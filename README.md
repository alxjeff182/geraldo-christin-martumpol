# Geraldo & Christin — Martumpol

Undangan digital **Martumpol** (Patua Hata, Marhusip, Martonggo Raja, Martumpol).

- Static parallax + animasi buku terbuka
- Domain: `geraldo-christin-martumpol.vercel.app`

## Lokal

Buka `index.html` via server statis, contoh:

```bash
npx serve .
```

## Deploy

```bash
npx vercel --prod --yes --name geraldo-christin-martumpol
```
